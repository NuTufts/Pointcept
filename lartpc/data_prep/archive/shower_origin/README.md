# Shower-Origin Dataset Production (exploratory project, archived)

Scripts that produced the shower-origin training datasets
(`convert_larlite_to_showerorigin_h5.py`, `inspect_new_shower_origin_targets.py`).
The identically-scoped `merge_reco_truth_showerorigin.py` lives in
`../../training_data/` (it is step 4 of the gen-2 pipeline).

Related: configs in `configs/lartpc/shower_origin/`, analysis in
`lartpc/larformer_analysis/archive/shower_origin_reco_scripts/`, spec in
`docs/reference/shower_origin_spec.md`.
