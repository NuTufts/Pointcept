# LArTPC Data Prep

This folder contains scripts to process the simulated data at Tufts
into the hdf files needed to train the PT-v3 model.

We use code in the [larflow](https://github.com/nutufts/larflow) repository to process this data.

`larflow` is a package setup within the [ubdl](https://github.com/larbys/ubdl) stack.
